# 编辑规则

## 硬性范围

- 行业：食品、餐饮、酒水、饮料、美妆、日化、服装、医药、零售。
- 主体：优先龙头企业、独角兽、国内企业及外企中国业务。
- 时效：所有计入搜索门槛和最终选题的信源，发布时间必须在上海时区搜索日当天及此前3个自然日内。缺失发布时间、超期或未来时间均不合格。
- 搜索量：选题前至少逐条记录100条四天窗口内、按规范化URL去重的资料，且必须使用Web Search并优先搜索S级来源。
- 数量：每日至少提交4个成熟选题；不足4个时如实报告，不用低质量题凑数，但仍须输出Word。
- 形式：最新事件加2-3个可由事实支撑的矛盾点。

## 选题合格线

一个成熟选题必须回答：

1. 今天为什么要写？
2. 事件中有哪些关键数字或动作？
3. 表象与经营现实之间有什么张力？
4. 每个矛盾点能否继续找到财报、公告、行业数据或采访对象支撑？
5. 与网易已有内容相比新增了什么？
6. 哪一条四天内的S级原始信源直接支撑事件、数字和核心结论？

## 推荐标题公式

`公司标准名 + 最新事件/动作 + 关键数字 + 核心矛盾`

不要使用空泛问句、营销口号、未经证实的定性或只有情绪没有事实的负面词。

## 内容拆解

- 第一部分：最新事件和直接事实，交代时间、动作、数字及背景。
- 第二部分：经营或战略矛盾，用财务、渠道、产品、供应链等证据展开。
- 第三部分：更长期的增长、竞争、治理或行业矛盾，给出延展和采访方向。
- 每部分使用编号分论点；分论点下的每个事实段统一使用`短结论：对应数据`。
- 短结论控制在2至10个汉字，必须直接概括后面的数据，结论和数据一一对应。
- 事实段不加项目符号，不使用短横线或手工字符模拟项目符号。
- Word正文禁止出现半角短横线、中文破折号和短破折号。

## 禁止项

- 不给企业做广告，不照抄宣传稿。
- 不为负面而硬黑；评价必须与证据强度匹配。
- 不使用无法回溯的截图、聚合摘要或匿名爆料作为核心证据。
- 网易财经已发同题时，网易号外原则上不再发。
- 不把“未查到”写成“不存在”，不把“未访问”写成“已查重”。
- 不因搜索或选题未达标而省略Word；Word必须如实记录完成状态、实际选题和信息来源。
