# A4 课堂讲义样张

这个目录用于比较三种 A4 竖版课堂讲义 PDF 风格。样张只用于定版前预览，不参与当前默认备课生成链路。

三种样式使用同一套代表内容：

- 一页概念/基础题。
- 一页大题。
- 一页小题组。

课堂 PDF 的内容边界：

- 只放题目、必要图形、题号、页眉和大块书写留白。
- 不放答案。
- 不放方法骨架。
- 不放提示或完整过程。

生成文件：

- `clean-competition.tex` / `clean-competition.pdf`：清爽竞赛讲义风。
- `school-paper.tex` / `school-paper.pdf`：学校试卷风。
- `light-color.tex` / `light-color.pdf`：轻量彩色讲义风。
- `preview-*.png`：每种 PDF 的页面预览图。
